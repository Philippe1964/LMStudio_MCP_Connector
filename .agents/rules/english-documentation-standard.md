# Engineering Standard: Default Language Policy (English)

This mandatory standard applies across all source code, documentation, scripts, wikis, and configuration files in this workspace.

## 1. Core Principle: English as Default Language
All project deliverables must systematically use **English** as their primary and default language:
- **Source Code**: Code comments, JSDoc/TSDoc blocks, function/variable names, log messages, error messages, and CLI outputs.
- **Documentation**: `README.md`, all GitHub Wiki pages, architecture specifications, API documentation, and changelogs.
- **Embedded Web GUI**: All dashboard UI labels, buttons, metrics cards, form placeholders, and status badges.
- **Git & Automation**: Commit messages, pull request descriptions, script terminal outputs, and automated review comments.

## 2. Rationale
- Ensures international accessibility, maintainability, and open-source readiness.
- Aligns with modern Model Context Protocol (MCP) standards and global developer tooling ecosystems.
- Prevents bilingual inconsistencies across documentation, codebases, and user interfaces.
